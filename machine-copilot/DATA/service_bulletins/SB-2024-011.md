# Service Bulletin SB-2024-011
## X/Y-Axis Ball Screw Replacement — Apex-3200

**Applies to:** Apex-3200, all serial numbers with firmware < 4.2.1
**Classification:** Qualified technician only. Requires facility LOTO procedure.

### Summary
This bulletin supersedes the ball screw replacement steps in the original
Section 8 manual with updated torque specifications following a field
correction on the retaining nut assembly.

### Required Tools
- Torque wrench, calibrated, 5-50 Nm range
- Ball screw support jig (P/N AX-330-JIG)
- Dial indicator, 0.001mm resolution

### Updated Torque Specification
Retaining nut torque: **28 Nm** (previous manuals incorrectly listed 35 Nm —
over-torquing at 35 Nm has been linked to premature bearing preload failure
in 6 field cases). Always confirm the machine's firmware version before
following torque specs; machines updated to firmware 4.2.1+ display the
corrected value directly on the maintenance screen.

### Procedure Overview
1. Power down and lock out per facility LOTO procedure.
2. Remove axis covers and disconnect the linear encoder cable.
3. Support the ball screw with jig AX-330-JIG before loosening end bearings.
4. Remove old ball screw assembly, inspect mounting surfaces for scoring.
5. Install new assembly, torque retaining nut to 28 Nm per this bulletin.
6. Re-calibrate backlash compensation via Axis > Backlash Compensation menu.
7. Run warm-up macro O9010 and verify positioning alarms (ALM-1104/1105)
   do not recur over a 30-minute test cycle before returning to production.
